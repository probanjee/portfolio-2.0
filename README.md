## 🌟 Key Highlights & Architecture

### 🤖 P.A.I. (Partial Automated Intelligence) Assistant
Built-in interactive AI assistant featuring:
- **Liquid Glass Widget UI**: 2 concentric liquid glass orbiting rings with rotating liquid droplets.
- **25% Ultra-Transparent Modal**: Semi-transparent glass window (`backdrop-blur-xl`) with custom scroll controls (`data-lenis-prevent`).
- **VS Code Code Syntax Highlighting**: Real-time syntax coloring for code snippets and user terminal inputs.
- **Interactive Capabilities**:
  - 🧮 **Math Problem Evaluator**: Evaluates expressions like `15 * 8`, `sqrt(16)`, `100 / 4`.
  - ⏰ **Real-Time Clock**: Live date, time, and timezone display.
  - 🌤️ **Live Regional Weather**: Accurate local weather reports.
  - 🤖 **Humorous Dialogue Matrix**: Witty responses for existential questions, developer memes, and a hilarious 3-stage escalation flow.
  - 👤 **Session Name Memory**: Interactive greeting and name recall.

### 🛡️ Featured Security & System Projects
1. **VIGILANCE Enterprise Honeypot Platform**:
   - Dual-honeypot deployment mimicking SSH/HTTP endpoints (Ports 22/80).
   - Real-time telemetry log pipeline (<50ms delay) with Apache Kafka message queue and Slack/Discord webhook alerts.
2. **SQLSense — Instant SQL AST Query Explainer**:
   - Full-stack developer tool parsing SQL syntax into clause-by-clause visual explanations.
3. **C++17 Secure Cryptographic File Engine**:
   - High-throughput stream cipher engine processing up to 250MB/s with SHA-256 integrity verification.

## 🚀 Quick Start & Local Setup

### Prerequisites
Make sure you have [Node.js](https://nodejs.org/) (v18 or higher) installed.

### Installation

```bash
# 1. Clone the repository
git clone https://github.com/probanjee/portfolio-2.0.git

# 2. Navigate into the project folder
cd portfolio-2.0

# 3. Install project dependencies
npm install

# 4. Start the development server
npm run dev
```

The application will be running live at `http://localhost:5173/`.

### Production Build

```bash
# Generate optimized production bundle
npm run build

# Preview production build locally
npm run preview
```

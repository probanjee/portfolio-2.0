A cinematic developer portfolio built with a premium AI security startup aesthetic — featuring glassmorphism, micro-animations, and immersive motion architecture.

---

## Design Philosophy

Built to move beyond generic templates. Every detail is intentional:

- **Cinematic UI** — Deep slate palettes with blue, cyan, and purple accent systems
- **Glassmorphism** — Translucent layered panels with atmospheric blur and subtle borders
- **Micro-Animations** — Framer Motion powered transitions, drag gestures, and interactive feedback
- **Cyber Visual Language** — Orbital rings, terminal-style elements, and startup-grade presentation

---

## Features

| Feature | Description |
|---|---|
| 🌀 Swipeable Hero Orb | Drag/swipe carousel between 3D avatar and profile image |
| 🌓 Adaptive Theme Engine | Persistent dark/light mode via localStorage and CSS variables |
| 🛰️ Scroll-Spy Navigation | Viewport-aware nav with smooth scrolling and active section sync |
| 📟 Terminal Contact Interface | Animated terminal-inspired communication section |
| 📂 Project Showcase | Animated cards for cybersecurity, full-stack, and backend projects |
| 📄 CV Download | Centralized secure CV handling via Vite public asset serving |

---

## Stack

- **Framework** — [React.js](https://reactjs.org/)
- **Build Tool** — [Vite](https://vitejs.dev/)
- **Styling** — [Tailwind CSS](https://tailwindcss.com/)
- **Animations** — [Framer Motion](https://www.framer.com/motion/)
- **Icons** — [Lucide React](https://lucide.dev/)
- **Data** — Centralized `portfolioData.js`

## Getting Started

```bash
# Clone
git clone https://github.com/probanjee/portfolio-2.0.git

# Install
npm install

# Develop
npm run dev

# Build
npm run build
```
